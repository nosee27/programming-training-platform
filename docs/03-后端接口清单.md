## 说明

- 权限码与数据库 `sys_permission.permission_code` 一一对应，超级管理员在 JWT 中的权限为 `["*"]`（放行全部）。
- 分页参数统一为 `page` / `size` / `keyword`，返回 `{ list, total, page, size }`。
- 删除接口默认是**逻辑删除**（`deleted = 1`），考勤、评价、授课安排、课程大纲等关联表为物理删除。
- 缴费、成绩、考勤等写操作在服务层使用事务与唯一键 UPSERT，详见 `server/services/*.js`。
