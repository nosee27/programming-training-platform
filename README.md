# 编程培训平台管理平台（江京教育）

面向编程培训机构的教务管理平台。一套业务数据，三端视图：**管理端**（教务/管理员）、**教师端**（教学执行）、**学生端**（学员自助查询），覆盖学员、教师、课程、班级、课表、考勤、缴费、成绩、学习档案、作品、课件与新闻。

> 课程作业项目。数据均为虚构演示数据，不含任何真实学员信息。

---

## 功能概览

| 端 | 功能 |
| --- | --- |
| **教学管理（管理端）** | 工作台（数据概览/待办）、系统管理（用户/角色/权限）、新闻中心、课件资源、教师管理、学生管理、课程管理、班级管理、成绩管理 |
| **教师端** | 教师工作台、我的授课、我的课表、学员考勤、成绩录入、成绩查询、教学评价、学员档案、作品点评、课件资源、新闻中心 |
| **学生端** | 我的主页、我的成绩、我的课表、我的考勤、学习档案、我的作品、课件下载、新闻中心、个人中心 |

### 模块说明

- **系统管理**：账号 / 角色 / 权限（目录-菜单-按钮三级，`parent_id` 自关联），支持角色授权、用户分配角色、重置密码。
- **学生管理**：基本信息（学号唯一、逻辑删除、按状态统计在读人数）、考勤（按"学员+课程+日期"唯一，重复录入覆盖）、缴费（应收/优惠/实收/欠费自动计算）、学习档案（阶段/课时/测评/能力标签/评语）、学生作品（提交与教师点评）。
- **教师管理**：基本信息、授课安排、教学评价。
- **课程 / 班级 / 成绩**：课程与大纲；班级成员与课表；成绩批量录入（按唯一键 UPSERT）、查询导出、分数段与课程统计。
- **新闻中心**：全部 / 平台公告 / 行业资讯 / 赛事动态 四个标签页，支持发布、编辑、置顶、下线、删除。
- **课件资源**：上传（multer 落盘）、下载计数、按分类聚合。

## 核心设计

| 设计点 | 做法 |
| --- | --- |
| 一键登录 | 登录页无账号密码、无角色选择；后端签发 JWT 并下发权限码 |
| 权限控制 | 菜单/按钮按权限码渲染，**接口层二次校验**（前端绕过无效） |
| 数据范围 | 登录时绑定 `studentId` / `teacherId`，服务端按身份强制收窄查询；管理端不受限 |
| 数据一致性 | 唯一键 + 事务：成绩/考勤重复录入覆盖；缴费收款后重算欠费，收款不得超过欠费 |
| 架构 | 三层：表现层（静态页面）→ 事务处理封装层（routes / services / dao）→ MySQL |

## 技术栈

- **前端**：原生 HTML5 + CSS3 + JavaScript（ES6），无框架、无构建步骤
- **后端**：Node.js + Express 4，mysql2 连接池，jsonwebtoken，multer
- **数据库**：MySQL 8.0（InnoDB / utf8mb4），21 张表
- **鉴权**：一键登录（JWT）+ RBAC（角色-权限）+ 数据范围控制

## 快速开始

### 方式一：免安装看界面（30 秒）

1. 下载仓库（`Code → Download ZIP`）或 `git clone`
2. 用 Chrome / Edge 打开 `web/login.html`
3. 点「一键登录」

不需要 Node、不需要 MySQL、不联网。`file://` 打开时自动使用内置演示数据，所有页面、三端切换、弹窗、表格分页都能点。

> 演示数据只读：新增/修改/删除不会真正保存，刷新后恢复。要看真实写入请用方式二。

### 方式二：完整部署（真实数据库）

**前置**：Node.js 20+、MySQL 8.0

```bash
# 1) 建库与初始化数据
mysql -u root -p < sql/01-schema.sql
mysql -u root -p < sql/02-seed.sql

# 2) 配置
cd server
cp .env.example .env        # Windows: copy .env.example .env
# 编辑 .env：填写 DB_PASSWORD；端口默认 3001（3000 常被本地软件占用）

# 3) 启动
npm install
npm start
```

浏览器打开 **http://localhost:3001/login.html**，点「一键登录」。

健康检查：`GET /api/health` 返回 `{"code":0,"data":{"server":"ok","database":"ok"}}`。

### 默认账号

- 一键登录默认使用 `admin`（覃艳，超级管理员），可在 `.env` 里用 `DEFAULT_LOGIN_USERNAME` 改成 `t1001`（教师）或 `s2026001`（学员）。
- 演示用账号：`admin` / `jiaowu` / `t1001` / `t1002` / `s2026001` / `s2026005` / `s2026007` 等，均无密码（一键登录不校验密码）。
- 登录后在 **个人中心 → 演示身份切换** 可在管理员 / 教师 / 学员之间切换，直观对比三端菜单与数据范围。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 启动报 `EADDRINUSE` | 端口被占用。改 `server/.env` 的 `PORT`，并同步修改 `web/assets/js/config.js` 中的端口 |
| `/api/health` 报数据库不可用 | MySQL 未启动，或 `.env` 中 `DB_PASSWORD` 不对 |
| 页面出现黄色「演示数据」提示 | 前端没连上后端，已自动降级为内置演示数据；检查后端是否启动、端口是否一致 |
| 修改后刷新就没了 | 说明当前是演示模式（无后端）。完整部署后写入 MySQL 才会持久化 |
| 登录后 403 无权限 | 当前身份没有该页面权限（如学员访问管理端工作台），用「演示身份切换」换身份 |
